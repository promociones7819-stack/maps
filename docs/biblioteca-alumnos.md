# Biblioteca por alumno

En Biblioteca, selecciona un alumno para consultar sus rutas GPX y trayectorias. Se incluyen los recorridos vinculados a sus clases y las sesiones grabadas con su identificador, aunque dos alumnos tengan el mismo nombre.

Cada tarjeta tiene Asignar. Marca uno o varios alumnos y selecciona una clase existente para cada uno. Si un alumno todavía no tiene clases, créala desde Alumnos. Asignar varias veces el mismo recorrido a la misma clase no añade duplicados.

Los vínculos usan el mismo recorrido de biblioteca y sus archivos originales: no se copian GPX, vídeo ni incidencias. Los cambios posteriores en ese recorrido común se verán desde todas las clases vinculadas. Para quitar un vínculo concreto, abre la clase en Alumnos y usa Quitar vínculo. Eliminar el recorrido de la biblioteca es una operación distinta que elimina el recurso común.

Los vínculos forman parte de las copias de seguridad de alumnos y de RutasAD. No comparten datos entre cuentas de usuarios diferentes.
